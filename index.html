HOW IT WORKS

算法说明

01 · 21 个关键点

MediaPipe Hands 在本地逐帧输出 21 个归一化关键点（0 手腕，4/8/12/16/20 指尖）。

02 · 手掌张开度 tension

以手腕到掌指关节的平均距离作为“手掌尺度”，再比较指尖的伸展量：

palm = mean(|wrist − mcp_i|)
ext_i = clamp((|tip_i − wrist| − |mcp_i − wrist|)
              / palm / 0.95, 0, 1)
thumb = clamp((|tip4 − mcp5| / palm − 0.62) / 0.85, 0, 1)

tension = 0.27·食指 + 0.24·中指
        + 0.19·无名指 + 0.15·小指
        + 0.15·拇指

距离在按画面宽高比校正后的坐标中计算；tension 再做指数平滑，消除抖动。

03 · 从张力到绽放

阈值映射 + smoothstep，中间区域平滑过渡；张开是爆发、收回是凝聚，两者用不同阻尼：

target = smoothstep(0.32, 0.66, tension)
if (target > spread) spread += (target − spread) × 0.62  // 张开
else                 spread += (target − spread) × 0.12  // 收回

tension < 0.32 聚雷 · 0.32 – 0.66 电离 · > 0.66 雷绽

04 · 放电与着色器

花体由 3 层 20 片放电束组成：每片花瓣用闭合叶形轮廓采样，62% 粒子贴在叶缘、10% 沿主脉、28% 稀疏填充内部。花苞是一颗电离球，80% 粒子填充球体，20% 沿 56 根细丝拉出尖刺。全部放电粒子由单个 THREE.Points 承载，顶点着色器用 uSpread 在雷球 / 雷花两套坐标间插值，并叠加电颤、爆闪与指尖斥力。

另有一层每帧重新生成的 LineSegments 动态电弧（72 条、每条 2 条分叉），以及勾出叶缘、主脉、侧脉的静态骨架；两者都会随 spread 与时间闪烁。最前方还有一层 Canvas 指尖雷电：js/lightning.js 用中点位移递归分形生成主弧、子分支与折返，按 8–15Hz 放电节拍重生成并做帧间插值；三层描边形成白芯 / 青蓝 / 紫蓝辉光，带 0.15s 余辉、低分辨率 bloom、随机强闪与相机震动。五指指尖、指骨、掌缘各自放电，指间距离近时会击穿出细小火花。

强闪由 js/flash.js 的三连击高斯脉冲驱动：雷球中心以 uFlashPower 照亮粒子内侧，曝光只在闪光瞬间短暂抬升；绽放时粒子沿 aVelocity 先炸出再回弹，握拳时轻微挤压。音效来自 assets/audio/electric-arc.mp3，由 js/audio.js 按张开度调整播放速率、低通截止和响度：握拳更闷更低，张开更亮更利。
